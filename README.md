  # Mario Torres

  ## Product-Focused Software Developer & AI Automation Builder

  I build practical software products that combine full-stack development, artificial intelligence, automation, and thoughtful user
  experience.

  My main project is **AthletesLab**, a health, nutrition, and sports-performance platform that I designed and developed from concept

  workflows, food recognition, meal analysis, databases, synchronisation, authentication, payments, and operational automation.

  I work across the entire product lifecycle: understanding the problem, designing the architecture, writing the software,
  integrating AI services, managing data, improving reliability, and turning ideas into usable products.
